# 🧮 Validação de Formulário - HTML + JavaScript

Este projeto foi desenvolvido como parte do curso da EBAC, com o objetivo de praticar a criação de formulários HTML e validações com JavaScript.

## 📌 O que o projeto faz?

- Cria um formulário com dois campos numéricos (A e B)
- Valida se o valor de B é maior que o de A
- Exibe uma mensagem positiva ou negativa com base na validação
